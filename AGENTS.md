# Coding Style

- Format project code with the root Prettier configuration and `npm run format`.
- Use four spaces for indentation, single quotes (including JSX attributes), and semicolons.
- Keep functions and components readable across multiple lines; break JSX attributes onto separate lines when needed.
- Preserve application behavior, content, structure, and design when a task asks only for formatting.
- Run `npm run format:check` after formatting changes.
